# 디자인 시스템

목업의 네이비 바탕, 선명한 블루 CTA, 붉은 제품 강조, 밝은 여백을 계승했습니다. 문구는 HTML 텍스트입니다.

| 토큰 | 값 | 쓰임 |
|---|---|---|
| navy | #0c2543 | 메인, 맞춤 제작 영역 |
| blue | #075bff | 버튼, 링크, 상담 |
| red | #fa304a | 강조 문구, 제품 배지 |
| ink | #172b42 | 제목과 본문 |
| muted | #697889 | 보조 설명 |
| bg | #f6f9fd | 페이지 배경 |
| line | #dce4ed | 경계선 |

- 한국어 시스템 산세리프: Pretendard → Noto Sans KR → 맑은 고딕. 외부 폰트 요청 없이 사용자 기기의 폰트 사용.
- 최대 본문 너비 1200px. 1440px에서 좌우 120px 여백, 모바일 좌우 18px.
- 데스크톱 H1 66px(홈)/46px(서브), 모바일 43px/32px. 본문 14~17px.
- 상품 3열 → 2열, 설치사례 3열 → 모바일 1열. 390px에서 하단 전화·견적 버튼 고정.
- 버튼 최소 높이 44~48px, 둥근 모서리, 명확한 포커스 테두리. 메뉴는 Escape로 닫고 토글로 포커스 반환.
- 사진 비율을 보존하는 object-fit 사용. 제품은 contain, 현장은 cover.
- 카드 이동만 작은 hover 효과로 사용. reduced-motion 환경에서는 전환 제거. 점멸 없음.
- 제목은 페이지마다 H1 한 개, 의미별 H2/H3. 건너뛰기 링크, 한국어 alt, 이미지 크기, 지연 로딩 적용.
