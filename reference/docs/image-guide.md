# 이미지 사용과 교체

## 출처

사용자가 제공한 `안전보안관_카페24_홈페이지_전체목업.png` 한 장(1348×4738)에서 사진 영역을 잘라 최적화했습니다. 원본 파일을 수정하지 않았습니다. 외부 제품사진·기업 로고·AI 합성사진은 사용하지 않았습니다.

| 파일(assets/images) | 추출 영역 | 사용 |
|---|---|---|
| hero.webp | 목업 메인 우측 산업현장·붉은 경광등 | 홈 메인 전체 배경 |
| voice.webp | 흰색 안내기 | 음성안내기, 타이머 제품군 참고 |
| sensor.webp | 센서형 안내 장비 | 센서형 음성경보기 |
| beacon.webp | 빨간 경광등·스피커 | 고출력, 음성경광등 제품군 참고 |
| remote.webp | 리모컨 제품 카드 | 리모컨 음성경광등 |
| voltage.webp | 고전압 구역 설치 | 설치사례, 건설·야외 솔루션 참고 |
| forklift.webp | 지게차 장착 | 설치사례, 산업·주차장 솔루션 참고 |
| market.webp | 하나로마트 입구 | 설치사례, 건물·매장 솔루션 |

각 파일에 대응하는 `-small.webp`(최대 360px)가 있습니다. WebP quality 88/82, 총 16개 파일입니다. 제품 외형은 생성·변형하지 않았으며 원본의 카드 배지나 사진 내 표기는 일부 포함될 수 있습니다. 홈페이지의 모든 제목·설명·버튼은 실제 HTML입니다.

## 공개 전 권장 교체

목업에서 추출한 사진은 원래 상품 원본보다 작아 큰 화면에서 흐릿할 수 있습니다. 개별 제품 원본과 산업현장 사진을 확보하면 같은 파일명으로 교체하고 HTML의 width/height, srcset의 실제 너비를 함께 맞추세요. 메인 배경은 1920px 이상, 제품은 800px 이상 권장합니다. 원본은 별도 보관하고 WebP 사본만 게시합니다.

센서·타이머·고출력 모델별 정확한 사진은 운영자가 확인해야 합니다. 원본 전체제품 단체사진과 스마트스토어 개별 상품사진은 별도로 제공되지 않아 추가하지 않았습니다. 설치사례 사진에서 추정할 수 없는 사양과 안내멘트는 예시로 명시했습니다.
