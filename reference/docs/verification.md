# 제작·검수 결과

## 결과

23개 정적 HTML 페이지를 제작했습니다. 페이지 및 신규 파일 목록은 [README](../README.md), 상세 연결 구조는 [사이트맵](sitemap.md)에 정리했습니다. 기존 프로젝트에는 `.git`만 있어 기존 스킨을 덮어쓴 파일은 없습니다.

로컬 HTTP 서버와 실제 Edge Chromium 브라우저에서 1440, 1024, 768, 390px 너비로 23개 페이지를 검사했습니다. **총 92개 페이지/화면폭 검사가 통과했습니다.** 원시 결과는 [verification.json](verification.json)에 있습니다.

| 내부 HTML 링크의 대상 존재 | 통과 |

| 스마트스토어 링크 | 지정 URL, 새 창, noopener 적용 |

| 제품 분류 URL, 필터, 검색, 빈 결과 | 통과 |

전화번호 HTML pattern의 최신 브라우저 정규식 호환성 오류를 발견해 길이 제한과 JavaScript 숫자 검증으로 수정한 뒤 전체 검사를 다시 통과했습니다. JavaScript 미실행 시 상담 fieldset은 비활성화되어 입력 내용을 전송하지 않습니다.

- [데스크톱 전체 PNG](../안전보안관_카페24_다페이지_홈페이지_전체목업.png): 1440×6095

전체 PNG에서 메인부터 제품·카테고리·솔루션·제작과정·설치사례·납품실적·블로그·상담·푸터까지 확인했습니다. 네이비와 블루 중심의 목업 디자인을 적용했습니다. 모바일은 제품 2열, 사례 1열, 햄버거 메뉴와 고정 상담 버튼을 사용합니다. 전체 페이지 캡처에서는 고정 하단 버튼이 최초 viewport 하단 위치에 표시됩니다.

## 적용과 남은 연결

[카페24 설치 안내서](cafe24-install-guide.md)에 각 페이지의 적용 파일, 공통 CSS/JS 삽입 위치와 모듈 교체 방법을 설명했습니다. 실제 상품·분류 번호, 게시판 목록/읽기/검색/쓰기, 회원·주문 기능, 문의 저장과 비공개 권한은 관리자에서 연결해야 합니다. 카페24 서버 기능과 외부 스마트스토어 구매 흐름은 이 로컬 검수 범위에 포함되지 않습니다.

회사 주소·사업자 정보·실제 개인정보 수집 문구도 운영자가 확정해야 합니다. 실제 구매후기를 생성하지 않았으며 스마트스토어 후기로 연결합니다. 인기 글은 조회수 기반 순위가 연결되지 않았음을 표시했습니다.

## 이미지

사용자 목업 한 장에서 제품 4종, 현장 3종, 메인 배경 1종을 추출해 WebP 16개(크기별 사본 포함)로 최적화했습니다. [이미지 목록과 교체 안내](image-guide.md)를 확인하세요. 일부 제품군은 참고 이미지를 공유하며 고해상도 원본으로 교체하면 선명도가 개선됩니다. 원본 파일은 수정하지 않았습니다.
